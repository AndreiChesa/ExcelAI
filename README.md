# AI & Machine Learning Foundations Portfolio

A comprehensive collection of practical Artificial Intelligence, Machine Learning algorithms, statistical modeling, and deep learning architectures implemented in Python. 

This repository ranges from low-level algorithms built from first principles (without high-level framework abstractions) to production-ready workflows utilizing modern machine learning tools.

---

## 🛠 Tech Stack & Frameworks

* **Languages:** Python
* **Machine Learning & Boosting:** Scikit-Learn, XGBoost, LightGBM, Optuna
* **Deep Learning & NLP:** PyTorch, TF-IDF Vectorization
* **Data Processing & Analytics:** Pandas, NumPy, Matplotlib
